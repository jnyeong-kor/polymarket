# API-X Polymarket Dashboard

Next.js + TypeScript dashboard prototype implementing the Autonomous Predictive Intelligence execution loop:

1. **[SCAN]** opportunity indexing over candidate markets.
2. **[REASON]** deep signal estimation and source verification.
3. **[VERIFY]** risk checks (fractional Kelly, stop-loss, budget guardrail, hallucination guard).
4. **[EXECUTE]** simulated order decisioning and expected value tracking.
5. **[ADAPT]** strategy adaptation trigger logging.

## Run

```bash
npm install
npm run dev
```

Open <http://localhost:3000>
